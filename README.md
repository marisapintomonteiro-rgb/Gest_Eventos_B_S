# Gest_Eventos_B_S
Aplicação web para planeamento e gestão de eventos temporários — Projeto de Aplicações Informáticas.
# Bebe e Siga

Projeto desenvolvido no âmbito da unidade curricular de Aplicações Informáticas.

A aplicação tem como objetivo apoiar o planeamento e a gestão de eventos temporários, incluindo ementas, produtos, fornecedores, compras, vendas, stock e análise de resultados.

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- Node.js
- MySQL

## Regras de programação
Para a criação deste site vamos utilizar o vibe coding, é uma forma de criar software usando linguagem natural para instruir uma inteligência artificial a gerar o código por nós. Vamos utilizar o CODEX que é um agente apoiado por vamos LLM's.
